# 🌐 Site Institucional & Portfólio Profissional

Seja bem-vindo(a) ao repositório do meu site institucional! Este projeto foi desenvolvido do zero para funcionar como minha vitrine digital, apresentando meus serviços, minha stack tecnológica e meus principais projetos como Desenvolvedora Front-End.

🚀 **Confira o site em produção:** [Acesse aqui o projeto online](https://ingrid1322.github.io/meu-site-institucional/)

---

## 📱 Sobre o Projeto

O site foi planejado com foco em **alta conversão, performance e experiência do usuário (UX/UI)**. Ele conta com uma estrutura semântica limpa, seções estratégicas de apresentação profissional, exibição de portfólio real e total integração com canais de atendimento direto (como o WhatsApp).

### Principais Recursos:
- **Design 100% Responsivo:** Adaptado perfeitamente para computadores, tablets e smartphones.
- **Menu Hambúrguer Fluido:** Implementado de forma nativa para navegação móvel dinâmica.
- **Seção de Portfólio Personalizada:** Exibição direcionada de aplicações de alto nível (Dashboards, Angular e IA).
- **Botão Flutuante do WhatsApp:** Focado em facilitar o contato e aumentar a conversão de clientes.

---

## 🛠️ Tecnologias Utilizadas

Para garantir um carregamento rápido e total controle sobre a estrutura do projeto, utilizei tecnologias puras (**Vanilla Web**):

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização moderna baseada em variáveis de design, Flexbox e **CSS Grid** para os layouts responsivos.
- **JavaScript (ES6+):** Lógica nativa para controle de estado do menu e interações de rolagem.

---

## 💼 Especialidades em Destaque no Portfólio

Dentro deste site, destaco minha experiência no desenvolvimento de soluções corporativas completas, incluindo:
1. **Painéis Analíticos (Dashboards):** Estruturados em **Angular & TypeScript** com validações robustas (Reactive Forms).
2. **Integrações com IA:** Dashboards focados em métricas preditivas e inteligência de dados.
3. **Interfaces Responsivas:** Projetos construídos com foco em usabilidade e performance móvel.
